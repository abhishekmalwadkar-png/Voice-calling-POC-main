Remote Machine Setup Guide

To view logs from your remote Windows machine in this portal without logging in every time:

Step 1: Check your local Portal address
Your local machine IP address is: YOUR_IP
If both machines are on the same network/VPN, use: http://YOUR_LOCAL_IP:8088/api/ingest.
If cross-network / internet, start the portal with --tunnel to get a public URL!

Step 2: Copy the remote_agent folder to your remote machine
The folder contains log_streamer.py and run_remote.bat.

Step 3: Run on the Remote Machine
On your remote machine, edit run_remote.bat with your portal URL and double-click it. It will launch start_server.bat and stream every line live here!

set PORTAL_URL=http://YOUR_IP:8088/api/ingest
run_remote.bat
